# Mini Mercado da Sami

Sistema de registro de vendas para um mini mercado interno. O comprador escaneia
um QR code, informa nome e sobrenome, seleciona os produtos, escolhe a forma de
pagamento (na hora ou no fim do mes) e confirma a compra.

## Tecnologias

- Python / Django
- SQLite (banco de dados)
- HTML + CSS (sem framework de frontend)
